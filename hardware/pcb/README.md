# PCB Design

This folder contains the PCB design files for the sensing node used in the Smart Grain Storage Monitoring System.

The PCB is intended to integrate the main electronic components of the node into a compact and reliable hardware platform suitable for later enclosure integration and field deployment.

## Contents

This folder may include:

- PCB layout files
- PCB source/design files
- Top and bottom layer views
- 3D PCB renders
- Gerber/fabrication files
- PCB dimensions
- Connector and mounting information

## Design Purpose

The PCB is designed to replace the current prototype wiring and provide a more compact, structured, and reliable implementation of the sensing node.

The board supports the main sensing-node functions including:

- ESP32-based processing
- Temperature sensor interfaces
- Communication-related connections
- Power and peripheral control
- Connections required for future humidity sensor integration
